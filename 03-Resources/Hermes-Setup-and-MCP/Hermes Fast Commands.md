# Hermes Fast Commands

## Open the web dashboard

Run this in Terminal:

```bash
hermes dashboard
```

The local dashboard opens at <http://127.0.0.1:9119>. To open Smoothy's profile directly, use:

<http://127.0.0.1:9119/chat?profile=smoothy_op_dir>

## Check the shared gateway

```bash
hermes --profile default gateway status
hermes --profile default gateway list
```

For the shared-gateway recovery procedure, see [[../Hermes Doctor_Restart Gate_Set up/Hermes Shared Gateway Restart Protocol]].
