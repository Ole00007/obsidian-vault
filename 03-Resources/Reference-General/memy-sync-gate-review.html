Closing the gap before Obsidian syncs to GitHub

Memy sorts and secures notes well, but currently lacks an independent human/owner checkpoint before publishing. This deck reviews the gap, proposes the simplest secure fix, and links every recommendation to its source standard.

The gap

What Memy does today

Files move from Inbox → project folder → GitHub with no mandatory pause for an independent owner to verify sensitive content was actually removed.

Where I agree

Your instinct is correct

Sorting the Inbox into project folders is necessary — but sorting alone does not certify a file is safe to publish. An independent reviewer must confirm it, matching separation-of-duties principles used in secure software delivery.

Simplest secure fix

Use GitHub's native controls instead of a custom system

Skip a custom YAML approval ledger. GitHub already provides an owner-routing and approval mechanism built for exactly this — CODEOWNERS + branch protection + secret scanning. Fewer moving parts, same security guarantee.

1. CODEOWNERS file

Maps project folders to Smothy or Admy automatically. No manual routing logic needed — GitHub assigns the reviewer the moment a Pull Request touches that folder.

2. Branch protection rule

Require CODEOWNERS review + passing status checks before merge is even possible. The approval is the merge — no separate hash ledger required.

3. Gitleaks pre-commit / CI check

Automated secret scan runs on every Pull Request as a required status check — blocks merge on detection.

4. GitHub Push Protection

Native secret scanning blocks known credential patterns at push time — a second, provider-level backstop.

Why this is simpler: the Pull Request itself becomes the audit trail and the approval record — tied automatically to an exact commit. No custom hash-matching database to build or maintain.
If you want more control

Alternative: explicit quarantine + hash-bound approval

More rigorous, more moving parts. Use this only if project-owner sign-off must be recorded independently of Git itself (e.g. for compliance).

Step-by-step: recommended flow

1
Local quarantine. New files land outside the Git repo, Git-ignored, until scanned.
2
Memy sorts + scans. Classifies content, matches it to a project, moves it into that project's working folder.
3
Memy opens a Pull Request instead of pushing to main.
4
CODEOWNERS auto-assigns Smothy or Admy based on the folder touched.
5
Gitleaks + secret scanning run automatically as required checks.
6
Owner reviews and approves — or requests changes, sending it back to step 2.
7
Branch protection merges only when both the review and the checks pass.
