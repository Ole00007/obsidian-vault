# ICA v3 - 1: Scope & Sources

## Step 0 (Mandatory)
Ask before starting:
1. Industry (top-level sector)
2. Sub-niche (specific category)
3. Country/region (never assume)
4. Customer segment (B2B/B2C, personas)

If already stated, restate understanding in one line, don't re-ask.

## Sources
Ask if user wants specific sources cited. If no answer: default to most reliable, reputable sources per expert consensus (primary regulators, registries, industry-body data, peer-reviewed research) - not just top-ranked retail sites.

See file 2 for workflow.
