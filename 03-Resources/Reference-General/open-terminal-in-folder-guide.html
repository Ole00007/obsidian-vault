Open the terminal in the right folder

Two ways. Pick one. Always check with pwd (Mac) or pwd / cd (Windows).

Way 1 · Terminal first, then go to the folder

macOS
  1. Press ⌘ Cmd + Space, type Terminal, press Enter.
  2. Type cd (with a trailing space).
  3. Drag the folder from Finder into the Terminal window. The path fills in.
  4. Press Enter.
cd ~/Documents/obsidian-vault/01-Projects/aLEXy
pwd
ls
Windows
  1. Press Win + X, then I (Terminal). Or Win + R, type powershell, Enter.
  2. Type cd and paste the folder path (in Explorer: click the address bar, Ctrl + C).
  3. Press Enter.
cd "C:\Users\YOU\Documents\obsidian-vault\01-Projects\aLEXy"
pwd
dir
Path has spaces? Wrap it in quotes: cd "My Folder". Different drive on Windows (say D:)? Use cd /d D:\path in cmd, or plain cd D:\path in PowerShell.

Way 2 · Open the folder first, then start the terminal from it

macOS

Once, enable it: System Settings → Keyboard → Keyboard Shortcuts → Services → Files and Folders → tick New Terminal at Folder.

  1. In Finder, right-click the folder.
  2. Choose Services → New Terminal at Folder.

Alternative: open Terminal, type cd , drag the folder in (Way 1).

Windows

Fastest:

  1. Open the folder in File Explorer.
  2. Click the address bar, type powershell (or cmd), press Enter.

Windows 11: right-click empty space in the folder → Open in Terminal.
Windows 10: hold Shift + right-click empty space → Open PowerShell window here.

Reverse trick: from terminal, open the folder

# macOS
open .
# Windows
explorer .
