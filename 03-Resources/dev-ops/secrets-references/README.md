# secrets-references

README for the `secrets-references/` subfolder.

What belongs here: where each secret lives (Railway variables, macOS Keychain, `.env` reference only), who rotates it, and rotation cadence. **Never store a secret value in this folder.**

One-line rule: record the secret name, location, and owner; the actual value stays in the vault/platform.
