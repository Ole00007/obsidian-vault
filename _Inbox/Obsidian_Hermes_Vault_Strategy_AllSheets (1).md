\---SHEET: Glossary---

																									  
	Glossary of Technical Terms																								  
	Plain-language definitions of every term used in your Obsidian/Hermes notes																								  
																									  
	Term	Simple Definition	Tiny Example	Where It Applies Here																					  
	Vault	A vault is just the main folder Obsidian treats as one connected notebook.	\~/Obsidian/ is your vault.	All your PARA folders live inside it.																					  
	PARA	A 4-category system for organizing files by how actionable they are: Projects, Areas, Resources, Archive.	'LexFlow MVP' \= Project; 'Health' \= Area.	Your top-level folder structure.																					  
	Inbox	A single catch-all folder where every new note lands first, before you decide where it really belongs.	You write a quick idea → saved in \_Inbox/ → sorted later.	Prevents notes from being misfiled by you or Hermes.																					  
	Frontmatter (YAML)	A small block of key:value data at the very top of a markdown note, wrapped in \--- lines, that describes the note (not the content itself).	\---\\ntitle: Client Call\\nstatus: draft\\n---	Required on every note per your AGENT\_RULES.md.																					  
	YAML	The simple text format frontmatter is written in (Yet Another Markup Language) — just 'label: value' pairs, no code needed.	tags: \[seo, client\]	Used inside frontmatter blocks.																					  
	Wikilink	A link between two notes written as \[\[Note Name\]\] — clicking it jumps to that note.	\[\[Alena Krot Website Plan\]\]	Rule: every note must be linked from at least one other note.																					  
	Tag	A label starting with \# that groups notes by topic, independent of folder location.	\#client \#seo	Used by Auto Note Mover to decide where a note should move.																					  
	Markdown (.md)	A plain text file format that lets you add bold, headers, links etc. with simple symbols — no special app required to open it.	\*\*bold\*\* or \# Heading	Every Obsidian note is a .md file — this is why Hermes can read it directly.																					  
	Plugin	An add-on that adds a feature to Obsidian, installed from the Community Plugins browser inside the app.	QuickAdd, Auto Note Mover.	Used to automate inbox sorting.																					  
	QuickAdd	A plugin that gives you fast templates/shortcuts to create pre-formatted notes (with frontmatter already filled in).	Press a hotkey → new 'Meeting Note' appears with tags pre-set.	Speeds up correctly-tagged note creation into \_Inbox.																					  
	Auto Note Mover	A plugin that automatically moves a note out of one folder into another once it matches a rule (usually a tag).	Note tagged \#project → auto-moved from \_Inbox to Projects/.	The mechanism that actually empties your Inbox.																					  
	.obsidian/ folder	A hidden configuration folder Obsidian creates automatically inside the vault the first time you open it in the app — stores plugin settings, themes etc.	\~/Obsidian/.obsidian/	Not something you or Hermes should hand-edit.																					  
	Hermes	Your local AI agent platform that can read and write files as instructed — in this case scoped only to the Obsidian vault.	Hermes creates a task note and saves it to \_Inbox/.	Governed entirely by AGENT\_RULES.md.																					  
	Territorial boundary	A safety rule limiting where an AI agent is allowed to read/write files, to avoid it touching unrelated folders like Desktop or Downloads.	Hermes can write to \~/Obsidian/ but not \~/Desktop/.	Defined in your AGENT\_RULES.md rule table.																					  
	Status lifecycle	A defined set of stages a note passes through, tracked in its frontmatter, so you and agents know its state at a glance.	draft → active → review → archived	Required 'status' field in frontmatter.																					  
	Flat vs deep folder tree	'Flat' means few folders with little nesting; 'deep' means many nested subfolders. Flat is easier to navigate and easier for AI agents to search.	Projects/LexFlow.md (flat) vs Projects/Work/2026/Q1/LexFlow/Notes.md (deep)	Your 4–6 top folders keep it flat; sub-notes use links/tags instead of nesting.																					  
	Daily notes	One markdown note per calendar day (named YYYY-MM-DD), used as a running log/journal entry point.	2026-08-06.md	Good scratchpad separate from Inbox — captures time-stamped context.																					  
	Filesystem-first	Meaning the vault is just plain files/folders on disk (not locked inside a proprietary database), so any script or agent can read it without an API key.	Hermes opens 2026-08-06.md with a normal file-read, no Obsidian API call needed.	Why this setup works well for AI agent integration.

\---SHEET: Inbox Explained---

																									  
	Where Does '\_Inbox/' Actually Live?																								  
	Direct answer to your question, step by step																								  
																									  
	Q: Is \_Inbox/ an Obsidian feature or a Hermes feature?																								  
	Neither, by default. \_Inbox/ is just a plain folder on your Mac's filesystem, inside your vault path (\~/Obsidian/\_Inbox/). Obsidian doesn't ship an 'Inbox' out of the box — you (or a plugin) create the folder manually, same as any other folder.																								  
																									  
	Q: So who creates it?																								  
	You created it (or your agent-setup script did) when the vault was scaffolded — evidenced by the AGENT\_RULES.md path \~/Obsidian/AGENT\_RULES.md and the rule text '\_Inbox/ first — never bypass it'. It's a convention, not built-in software.																								  
																									  
	Q: Does Hermes need to create this folder itself?																								  
	No — you only need to create \~/Obsidian/\_Inbox/ once, manually, in Finder or via 'mkdir \-p \~/Obsidian/\_Inbox' in Mac Terminal. After that, Hermes just writes new files into that existing path because AGENT\_RULES.md tells it to.																								  
																									  
	Q: Does opening Obsidian 'recognize' the Inbox specially?																								  
	No special recognition happens automatically. Obsidian just displays it as a normal folder in the left sidebar. The 'special' behavior (auto-sorting notes out of it) only happens if you install and configure the Auto Note Mover plugin inside the Obsidian app — that is a manual one-time setup step, separate from Hermes.																								  
																									  
	Q: What is Hermes's actual role here?																								  
	Hermes's role is to obey the rule when writing files: always save new agent-created notes to \~/Obsidian/\_Inbox/, never directly into Projects/Areas/Resources/Archive. Sorting out of the inbox is either done by you manually, or automatically by the Auto Note Mover plugin based on tags you (or Hermes, via frontmatter) assign.
