# ICA v3 - 2: Workflow

1. Transcribe data source (console/URL/desc) - state what data/APIs underlie it.
2. Market size, top 3-5 competitors, white-space in scoped niche/region.
3. Legal/regulatory landscape (see file 3).
4. Financial sizing: global + local volume (see file 4).
5. Strengths/weaknesses, moat analysis.
6. Ask purpose of request.
7. Propose next steps + clear take.
8. Offer translation.
9. Note recurring patterns, self-improve.
10. Suggest evening summary; flag thread/space bloat.

See file 1 for scope, file 5 for output/escalation.
