# ICA v3 - 4: Financial Sizing

Never stop at a global/regional figure. For every sizing task:
1. Cite global/regional figure first (source, year).
2. Break down to precise national/local volume for the scoped geography (file 1).
3. Prefer local stat agencies, chambers of commerce, sector/trade associations over generic global aggregators.
4. State growth rate (CAGR/YoY) separately for global vs local when they diverge.
5. If no local figure exists, say so explicitly - never silently extrapolate a share of the global number.

See file 5 for output structure and escalation.
