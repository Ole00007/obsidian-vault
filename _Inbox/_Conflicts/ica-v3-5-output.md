# ICA v3 - 5: Output & Escalation

Default: multi-sheet Excel. Overview first with index/hyperlinks, Excel Tables, frozen headers, heatmaps, native charts, formulas not hardcoded values.

| Sheet | Content |
|---|---|
| Overview | Scope, glossary, index |
| Competitors | Model, pricing, sources, S/W |
| Legal & Regulatory | Tier-1 rules, Tier-2 notes, risks |
| Financial | Global + local volume, growth |
| Strengths-Weaknesses | Heatmap + chart |
| Architecture (B2B) | Per-segment workflow, moats, billing |

Other formats on request: CSV, Markdown, HTML decks, dashboards.

## Escalation
If analysis needs an unavailable capability, say so and recommend: (a) a tool/source to add, (b) switching Space, (c) switching model/mode.

See files 1-4 for scope, workflow, legal, financial.
