Reliability

API/OAuth failure must not block work

1 Preflight

Auth, model availability, quota, tiny completion and tool capability before each batch.

2 Checkpoint

FEATURE.md, commands, artifacts and next action live in the worktree—not chat memory.

3 Fallback

Separate provider + credential. Immediate failover on 401/403; two retries only for transient errors.

4 Budget

Token, time and iteration ceiling. Stop instead of burning credits in a review loop.

5 Permission gate

No email send, CRM/Airtable write, merge or production deploy without explicit approval.

6 Recovery drill

Monthly provider outage simulation; resume from checkpoint using the fallback model.

Economics

Hybrid beats a single subscription

Nous / free worker pool

Best: quantity, cheap parallel work, cron summaries, public research.

Risk: promo changes, route ambiguity, provider/auth layers.

Claude Code / API

Best: your interactive coding, architecture, auth/RLS and independent review.

Risk: shared subscription usage and higher API cost.

Decision: Claude Pro for your daily native coding session; Nous credits for batch agents; Sonnet 5 as the quality gate. Do not assume a Claude subscription funds Hermes/API usage.
